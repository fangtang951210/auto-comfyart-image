# 素材04:踩坑实录(2026-10-27/28 全部亲历)

## 坑1:用浏览器自动化操作生成界面(反模式之王)
- 错误做法:MCP 不可用时(当时误判),用浏览器点生成按钮/填提示词/选模型
- 真实代价:一张图十几轮工具调用;UID 每次面板重渲染全失效;React 受控输入框模拟打字不触发 onChange(词填进 DOM 但应用层为空,点生成静默无请求)
- 教训:**浏览器只激活画布,生成全走 MCP**。UI 自动化在 React 富应用上是死路

## 坑2:自定义流 model id 想当然
- 试了 Krea2-Turbo、Krea2-Turbo.json 全报 unknown;真身是源码常量 **custom:generate**
- 教训:id 类参数先查文档/源码,文件名≠id

## 坑3:模型偏好 auto:false 滤掉自定义流
- 症状:UI 下拉有、MCP 列表没有(两条列表路径不同)
- 根因:models.json enabled 白名单不含 custom:generate
- 修复:auto:true + reload

## 坑4:画布激活绕远路
- 错误:从 hash 路由失败泛化出"必须列表页→真点击项目卡片"
- 真相:`?project=<id>` 直连一条命令;reload 后控制器上下文会断,重启控制器即可

## 坑5:MCP 超时≠失败
- "the ComfyArt page did not finish X within 20s"三种可能:画布没开/页面休眠/页面正忙(上次任务没完)。依次查:画布在不在→加载完没→队列空不空,别瞎重试

## 坑6:验收只看返回值
- generate_image 返回 ids ≠ 生成成功;wait_generation 的 status done 里单项也可能是 error
- 验收三件套:wait 结果逐项查 + ComfyUI history 模型名/文件名 + (可选)view_canvas 看像素
